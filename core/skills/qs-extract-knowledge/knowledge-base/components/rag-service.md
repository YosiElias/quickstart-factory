# RAG Service

## Overview

A FastAPI microservice that exposes a `/rag/query` endpoint for retrieval-augmented generation against a FAISS vector index. In the ansible-log-analysis quickstart, it indexes Ansible error documentation PDFs, generates embeddings via a TEI (text-embeddings-inference) sidecar service using the nomic-ai/nomic-embed-text-v1.5 model, and stores the resulting FAISS index and metadata in MinIO. The architecture splits into two container images: a lightweight init job that parses PDFs and builds the index, and a runtime service that loads the index from MinIO and serves queries.

## Tech Stack & Dependencies

- **Runtime:** Python >= 3.12
- **Container image:** `quay.io/rh-ai-quickstart/alm-rag` (runtime), `quay.io/rh-ai-quickstart/alm-rag:init` (init job)
- **Base image:** `registry.access.redhat.com/ubi8/python-312`
- **Key dependencies (runtime):** fastapi >= 0.116.1, faiss-cpu >= 1.7.4, httpx >= 0.27.2, minio >= 7.2.17, numpy >= 1.24.0, uvicorn >= 0.37.0
- **Key dependencies (init job):** pypdf == 6.1.3, langchain-community >= 0.3.27, langchain-core >= 0.3.27, requests >= 2.32.5, plus faiss-cpu, minio, numpy
- **Helm subchart:** `deploy/helm/ansible-log-monitor/charts/rag` (application chart, v0.1.0)

## Key Patterns

### Two-Image Split: Runtime vs Init Job

The component uses two separate Containerfiles to minimize the runtime image size. The init image (`Containerfile.rag-init`) includes PDF parsing and embedding generation dependencies; the runtime image (`Containerfile`) only needs FAISS, MinIO, and httpx. From `services/rag/Containerfile`:

```dockerfile
COPY services/rag/pyproject.toml ./
RUN uv sync --no-dev
COPY services/rag/index_loader.py services/rag/main.py .
ENTRYPOINT ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8002"]
```

The init image uses a separate dependency file and copies the full source tree. From `services/rag/Containerfile.rag-init`:

```dockerfile
COPY services/rag/pyproject.rag-init.toml ./pyproject.toml
RUN uv sync --no-dev --no-install-project --index-strategy unsafe-best-match
COPY services/rag/src/rag/ ./src/rag/
COPY services/rag/src/utils/ ./src/utils/
COPY data/knowledge_base/ ./data/knowledge_base/
ENTRYPOINT ["python", "rag_init_pipeline.py"]
```

### LATEST.json Pointer File for Build Status

MinIO stores the FAISS index alongside a `LATEST.json` pointer file that tracks build status (`BUILDING`, `READY`, `FAILED`). The init job sets status to `BUILDING` before uploading, then `READY` on success or `FAILED` with an error message on failure. From `services/rag/src/rag/embed_and_index.py`:

```python
pointer = {
    "status": "BUILDING",
    "error_message": None,
    "build_id": build_id,
    "build_ts": build_ts,
}
# ... upload index.faiss and metadata.pkl ...
pointer = {
    "status": "READY",
    "total_errors": len(self.error_store),
    "model_name": self.model_name,
    "build_id": build_id,
}
```

### Background Polling for Index Reload

The runtime service polls MinIO every 20 seconds for index availability. If the index is already loaded and `RAG_FORCE_REBUILD=true`, it checks `LATEST.json` for a new `build_id` and reloads automatically. From `services/rag/main.py`:

```python
async def poll_for_index():
    poll_interval = 20
    while True:
        if index_loader is not None and index_loader.index is not None:
            force_rebuild = os.getenv("RAG_FORCE_REBUILD", "false").lower() == "true"
            if force_rebuild:
                # Check LATEST.json for new build_id
                latest_build_id = pointer.get("build_id")
                if latest_build_id and latest_build_id != index_loader.last_loaded_build_id:
                    await index_loader.reload_index()
        await asyncio.sleep(poll_interval)
```

### Nomic Task Prefix Convention

The nomic-ai/nomic-embed-text-v1.5 model uses task-specific prefixes: `search_document:` for indexing documents and `search_query:` for queries. The embedder detects Nomic models by name and applies the prefix automatically. From `services/rag/src/rag/embed_and_index.py`:

```python
use_task_prefix = "nomic" in self.model_name.lower()
if use_task_prefix:
    prefixed_text = f"search_document: {composite_text}"
```

And in the query path in `services/rag/main.py`:

```python
query_text = f"search_query: {request.query}"
```

### Composite Embedding from Multiple Sections

Rather than embedding each section separately, the service creates composite embeddings by concatenating error title, description, and symptoms. This improves retrieval quality by matching against the full error context. From `services/rag/src/rag/embed_and_index.py`:

```python
composite_parts = []
if title:
    composite_parts.append(title)
if description:
    composite_parts.append(description)
if symptoms:
    composite_parts.append(symptoms)
composite_text = "\n\n".join(composite_parts)
```

### Init Container Dependency Chain

The Helm deployment uses an init container with an inline Python script that first waits for the Kubernetes init job to complete (via `oc wait` or `kubectl wait`), then polls MinIO for a `READY` status on `LATEST.json`. From `charts/rag/templates/deployment.yaml`:

```yaml
initContainers:
  - name: wait-for-rag-init-and-index
    image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
    command:
      - sh
      - -c
      - |
        python3 <<'PYTHON_SCRIPT'
        # Step 1: Wait for init job to complete
        if not wait_for_job_completion(job_name, namespace):
            sys.exit(1)
        # Step 2: Check MinIO index
        if not check_minio_index():
            sys.exit(1)
        PYTHON_SCRIPT
```

### FAISS Index Loading via Temp Files

FAISS requires file paths for reading indexes rather than byte streams. The `RAGIndexLoader` downloads artifacts from MinIO to a temp directory, loads them with `faiss.read_index()`, then cleans up. From `services/rag/index_loader.py`:

```python
temp_dir = Path(tempfile.mkdtemp(prefix="rag-index-"))
try:
    self.minio_client.fget_object(self.bucket_name, "index.faiss", str(index_path))
    self.index = faiss.read_index(str(index_path))
    # ... load metadata.pkl ...
finally:
    if temp_dir.exists():
        shutil.rmtree(temp_dir, ignore_errors=True)
```

### Connection Pooling for Embedding Service

The runtime service uses a persistent `httpx.AsyncClient` with connection pooling for calling the TEI embedding service, initialized at startup and closed on shutdown. From `services/rag/main.py`:

```python
embedding_client = httpx.AsyncClient(
    base_url=embedding_url,
    timeout=30.0,
    limits=httpx.Limits(
        max_keepalive_connections=20,
        max_connections=100,
        keepalive_expiry=30.0,
    ),
)
```

## Configuration

- **Environment variables:**
  - `MINIO_ENDPOINT` -- MinIO host (from `minio` secret, key `host`)
  - `MINIO_PORT` -- MinIO port (from `minio` secret, key `port`; default `9000`)
  - `MINIO_ACCESS_KEY` -- MinIO access key (from `minio` secret, key `user`)
  - `MINIO_SECRET_KEY` -- MinIO secret key (from `minio` secret, key `password`)
  - `RAG_BUCKET_NAME` -- MinIO bucket for index storage (default `rag-index`)
  - `EMBEDDINGS_LLM_URL` -- TEI embedding service URL (default `http://alm-embedding:8080`)
  - `RAG_MODEL_NAME` -- Embedding model name (default `nomic-ai/nomic-embed-text-v1.5`)
  - `RAG_FORCE_REBUILD` -- Force index rebuild even if one exists (default `false`)
  - `RAG_ENABLED` -- Enable/disable RAG index building in the init job (default `true`)
  - `PORT` -- Service listen port (default `8002`)
  - `DATA_DIR` -- Local data directory for temp storage (default `./data`)
  - `KNOWLEDGE_BASE_DIR` -- Directory containing source PDF files (default `./data/knowledge_base`)
  - `LOG_LEVEL` -- Logging level (default `INFO`)
  - `LOG_FORMAT` -- Log format: `pretty` or `json` (default `pretty`)
- **Config files:** `services/rag/src/utils/config.py` defines `EmbeddingsConfig` (hardcoded model name, env-based API URL) and `StorageConfig` (data paths)
- **Helm values (key overrides in `charts/rag/values.yaml`):**
  - `image.repository`: `quay.io/rh-ai-quickstart/alm-rag`
  - `service.port` / `service.targetPort`: `8002`
  - `rag.initImage.repository`: `quay.io/rh-ai-quickstart/alm-rag`, `rag.initImage.tag`: `init`
  - `rag.bucketName`: `rag-index`
  - `rag.maxWait`: `300` (seconds for init container timeout)
  - `rag.forceRebuild`: `false`
  - `rag.dataDir`: `/app/data/rag`
  - `rag.knowledgeBaseDir`: `/app/data/knowledge_base`
  - `livenessProbe.initialDelaySeconds`: `60`, `periodSeconds`: `30`
  - `readinessProbe.initialDelaySeconds`: `30`, `periodSeconds`: `10`
  - `resources.requests.memory`: `512Mi`, `resources.limits.memory`: `2Gi`

## Known Gotchas

- **FAISS requires file paths, not byte streams:** The `RAGIndexLoader` must download MinIO objects to temp files before loading because `faiss.read_index()` only accepts file paths. The temp directory is cleaned up in a `finally` block in `index_loader.py`.
- **TEI batch size capped at 30:** The embedding client batches texts in chunks of 30, below TEI's `MAX_CLIENT_BATCH_SIZE` of 32, as noted in the comment on line 137 of `embed_and_index.py`: `# TEI batch size limit (TEI MAX_CLIENT_BATCH_SIZE is 32, we use 30 to be safe)`.
- **MinIO `secure=False` hardcoded:** Both `index_loader.py` (line 59) and `minio.py` (line 54) set `secure=False` with the comment `# Use HTTP for internal OpenShift services`. TLS-enabled MinIO deployments require changing this.
- **`save_index()` and `load_index()` on `AnsibleErrorEmbedder` are deprecated:** Comments in `embed_and_index.py` state these are kept for backward compatibility with tests. Production code uses `save_to_minio()` / `ingest_and_index_to_minio()` and `RAGIndexLoader` respectively.
- **Init job skips rebuild if index exists:** The `rag_init_pipeline.py` checks MinIO for an existing READY index and returns early unless `RAG_FORCE_REBUILD=true`. This speeds up Helm upgrades but means knowledge base PDF updates require the force flag.
- **OpenShift random UID handled in init Containerfile:** The `Containerfile.rag-init` sets `chgrp -R 0 /app && chmod -R g=u /app` to support OpenShift's random UID assignment (group 0 convention).
- **Init container embeds inline Python in Helm template:** The deployment's init container contains a full Python script rendered via Helm templating (`{{ $backendFullname }}`, `{{ .Release.Namespace }}`). This makes the deployment template complex but avoids an extra utility image.

## Testing Notes

- Verify `/health` returns `{"status": "healthy", "index_size": N}` on port 8002 after index load
- Verify `/ready` returns 200 only when the FAISS index is loaded; returns 503 otherwise
- Test the query endpoint: `curl -X POST http://<svc>:8002/rag/query -H 'Content-Type: application/json' -d '{"query": "role name invalid", "top_k": 10, "top_n": 3, "similarity_threshold": 0.6}'`
- Trigger index reload via: `curl -X POST http://<svc>:8002/rag/reload`
- Check init job logs to confirm PDF parsing and MinIO upload succeeded
- The `tests/test_embeddings.py` script validates Nomic task prefix behavior with cosine similarity comparisons
- The `tests/test_queries.py` script supports interactive and batch query testing modes
